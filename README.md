# 📊 E-Commerce Sales & Customer Insights Dashboard

## 🚀 Project Overview
This project presents a comprehensive **E-Commerce Dashboard** designed to analyze customer behavior, product performance, and order trends.

The dashboard is built using structured data from the **workspace.ei_dashboard** database and provides actionable insights for business decision-making.

---

## 🎯 Objectives
- Analyze customer growth and engagement  
- Understand order patterns and status distribution  
- Identify top-performing and high-value products  
- Evaluate business structure and category distribution
